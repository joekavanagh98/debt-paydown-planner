# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability in this project, please
report it privately. Do not open a public issue.

Contact: joekavanagh@fastmail.com

I'll respond within 7 days to acknowledge receipt and discuss
next steps.

## Supported versions

This is a personal capstone project. The deployed backend
(`v5-backend/`, which holds v5 through v9 as in-place
modifications) is actively maintained at
debt-paydown-planner.onrender.com. The earlier standalone version
folders (`v1-vanilla/` through `v4-tailwind/`) are preserved as
historical artifacts and are not maintained.

## Scope

In scope:
- The deployed backend API
- The deployed frontend
- The shared calculator logic

Out of scope:
- The Render, MongoDB Atlas, and Vercel platforms themselves
- Anthropic's API
- Dependencies (please report to the upstream project)
